# Roberto Cavalleiro de Macedo — Advocacia

Template inicial de uma landing page institucional one-page, construído com HTML semântico, CSS e JavaScript puro.

## Abrir localmente

O site não exige instalação nem build. Abra `index.html` diretamente no navegador ou, na raiz do projeto, execute:

```powershell
python -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## Conteúdo que ainda precisa ser confirmado

- Número e UF da OAB
- Áreas reais de atuação e descrições
- Formação e experiência profissional
- Foto profissional
- Número do WhatsApp
- Perfil do Instagram
- Endereço de e-mail
- Texto definitivo da política de privacidade
- Autorização para manter o crédito do desenvolvedor no rodapé

Enquanto esses dados não forem recebidos, a página identifica os conteúdos provisórios e não abre contatos falsos.

## Estrutura

```text
.
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
    ├── icons/
    ├── images/
    └── logo/
```

O painel de acessibilidade permite ajustar o tamanho do texto, ativar alto contraste, destacar links e reduzir animações. As preferências ficam salvas no navegador quando o armazenamento local está disponível.
